# Bar Cut List

เว็บแอปสำหรับกำหนดเหล็กเสริมฐานรากและคาน แล้วคำนวณ bar schedule และ bar cut list ให้เหลือเศษน้อยที่สุด

เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งหรือ build (รองรับ GitHub Pages)

## โครงไฟล์
```
index.html        หน้าหลัก
css/style.css
js/catalog.js     ตารางเหล็กมาตรฐาน (RB6–DB25)
js/state.js       โครงสร้างข้อมูล, โหลด/บันทึก, import/export JSON
js/geometry.js    คำนวณพิกัด, การจบปลายเหล็ก, bar runs, ปลอก

js/schedule.js    แตกเหล็กทีละเส้น + จุดต่ออัตโนมัติ

js/summary.js     หน้าสรุป & แผนตัด
js/cutsheet.js    ใบตัดเหล็ก (รูปทรง SVG)

js/home.js        หน้ารวม
js/app.js         ประกอบหน้า / สลับหน้า
docs/data-model.md
```

## หมายเหตุ
- ปุ่ม Excel ใช้ SheetJS จาก CDN (ต้องออนไลน์) ถ้าโหลดไม่ได้จะส่งออกเป็น CSV (UTF-8) ทีละตารางแทน
- ใบตัดเหล็ก: ใช้ 🖨 พิมพ์ / PDF ของเบราว์เซอร์ (ตั้งค่าหน้า A4 แนวนอนให้อัตโนมัติ)
- ค่าหักการงอ ตั้งได้ใน ⚙ กฎโครงการ (ค่าเริ่มต้น 90° = 2d, 135° = 3d, 180° = 4d หรือเลือกไม่หัก) — รูปทรงแสดงระยะนอก–นอก ส่วนช่อง "ตัด" เป็นความยาวหลังหักแล้ว
